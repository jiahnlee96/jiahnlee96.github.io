# Jiahn Lee academic website

Static GitHub Pages site prepared from the October 2026 CV.

## Files
- `index.html` — main website
- `assets/` — CSS, JavaScript, portrait, favicon, and public CV PDF
- `.nojekyll` — keeps GitHub Pages from applying Jekyll processing
- `404.html` — fallback page

## Publish on GitHub Pages
1. Create a repository named exactly `jiahnlee96.github.io`.
2. Extract this package locally. Upload the **contents** of this folder to the repository root; do not upload only the ZIP file.
3. Confirm `index.html` is visible at the top level of the repository and `assets/` is a folder beside it.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. After deployment completes, the site should be available at `https://jiahnlee96.github.io/`.

## Updating later
Replace/edit the relevant files in the same repository and commit to `main`. GitHub Pages will redeploy automatically.

## CV privacy
The website package uses a web-safe copy of the uploaded final CV in which the phone number is removed. The original uploaded CV is not modified.
